A Python console application that analyzes password strength using multiple validation and scoring checks.

---

## 📖 About

Password Strength Checker is a console-based Python application that evaluates passwords using multiple validation rules and assigns an overall strength rating based on a scoring system.

It checks for:

* 📏 Password Length
* 🔠 Capital Letters
* 🔡 Small Letters
* 🔢 Digits
* 🔐 Special Characters

Finally, it classifies the password as:

* 🟢 Strong
* 🟡 Medium
* 🔴 Weak

---

## ✨ Features

* Console-based application
* Colorful output using Colorama
* Password strength scoring system
* Multiple password validation rules
* Continuous password checking
* Clear and easy-to-follow Python implementation

---

## ⚙️ Requirements

Python 3.x

Install Colorama before running the program:

```bash
pip install colorama
```
