---

## 📖 About

Password Strength Checker is a simple console-based Python application developed for learning Python fundamentals.

The program analyzes a password using multiple validation rules and displays an overall password strength.

It checks for:

- 📏 Password Length
- 🔠 Capital Letters
- 🔡 Small Letters
- 🔢 Digits
- 🔐 Special Characters

Finally, it classifies the password as:

- 🟢 Strong
- 🟡 Medium
- 🔴 Weak

---

## ✨ Features

- Beginner-friendly Python code
- Console-based application
- Colorful output using Colorama
- Password Strength Scoring System
- Multiple password validation rules
- Easy to understand and modify

---

## ⚙️ Requirements

Python 3.x

Install Colorama before running the program:

```bash
pip install colorama
```
